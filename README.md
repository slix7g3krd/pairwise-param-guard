# pairwise-param-guard

网关把同名查询参数直接交给后端后，HTTP 参数污染就开始生效：前端只校验第一个 `role=user`，后端取最后一个 `role=admin`；`?id=1&id=2` 在数组和标量之间来回变；编码后的同名键没有归一，`%72ole` 绕过白名单；分号被当成参数分隔符，能注入额外键；空值和重复空键让业务默认值生效；大小写不同的键被当成两个字段；`id[]=1` 和 `id[0]=1` 都能进数组解析；代理和框架取值顺序不一致；重复键没有审计；错误页把完整参数表回显。security/param_guard.py 是核心，tests/test_param_guard.py 15个红。要修的是：重复键拒绝；编码归一；分隔符统一；空键过滤；大小写归一；数组语法拒绝；键白名单；取值顺序固定；重复审计；错误脱敏。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：漏洞检测与攻防；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
